# Supermarket Checkout API

A FastAPI-based backend service implementing a supermarket checkout system using MVC architecture.

## Features

- RESTful API for supermarket checkout
- MVC architecture implementation
- Special offers and pricing rules support
- Input validation and error handling

## Prerequisites

- Python 3.8 or higher
- pip (Python package installer)
